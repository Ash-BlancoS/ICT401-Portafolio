## Resumen
 
Este proyecto propone el diseño de un organizador de cables de dos piezas Base y Tapa pensado para estudiantes, teletrabajadores y cualquier persona que use múltiples dispositivos electrónicos en su escritorio. El usuario enrolla el cable alrededor del gancho de la base y cierra la tapa mediante un sistema de encaje a presión, manteniendo el cable ordenado, oculto y en una posición fija sin necesidad de herramientas adicionales para el uso diario. El modelo se desarrolla de forma paramétrica en Fusion 360, lo que permite ajustar dimensiones como la profundidad de la caja sin reconstruir la pieza completa, reduciendo así el desorden visual y el riesgo de tropiezos en espacios de trabajo o estudio.
